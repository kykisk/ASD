## 주의사항

> ⚠️ **연구 배치 (#13)**: PubMed API + AI 요약으로 **5~10분** 소요. 먼저 실행하고 다른 항목을 테스트하는 동안 기다리세요.

> ⚠️ **Admin 토큰**: 연구 배치는 SYSTEM_ADMIN 권한 필요. 어드민 계정으로 로그인 후 토큰 발급.

> ⚠️ **activityLogId/articleId**: 댓글, 북마크 테스트는 실제 존재하는 ID 필요. 먼저 커리큘럼 활동 로그 또는 연구 피드에서 ID를 확인하세요.
